# Cloud-data-processing-and-visualization
Project Overview

Cloud Data Processing and Visualization is a cloud-based data engineering and business intelligence project developed using Microsoft Azure services and Power BI. The project focuses on processing raw CSV datasets, performing data transformation and wrangling operations, storing processed data in cloud storage systems, and generating interactive dashboards for visualization and analysis.

The system demonstrates how cloud technologies can be used to manage data efficiently through ETL (Extract, Transform, Load) processes and visualization techniques.

# Azure Process
1. Azure Blob Storage
2. Upload and manage CSV datasets.
3. Store raw input files in cloud storage.
# Azure Data Factory
1. Perform ETL operations.
2. Clean and transform dataset.
3. Apply filtering and aggregation using Dataflow and Power Query.
# Azure Data Lake / Azure SQL
1. Store transformed and processed data.
2. Manage structured cloud data efficiently.

# Power BI Visualization
1. Connect processed cloud data with Power BI.
2. Create interactive dashboards and reports.
3. Visualize trends, analysis, and business insights.
4. Enable easy understanding of processed data.
